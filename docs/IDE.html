IDEs e upload para o robô

O Arduino IDE funciona, mas é lento e tem um editor fraco. Podes escrever o código no editor que quiseres (VS Code, V-Agent, Neovim, etc.) e enviar para o robô pelo terminal com o arduino-cli.

Que IDE usar

  • Arduino IDE: o mais simples, ideal para começar. Escolher se nunca usaste nada. Download
  • VS Code + PlatformIO: editor melhor, compila e envia com um botão. Download VS Code | Instalar PlatformIO
  • arduino-cli: só terminal, funciona com qualquer editor (o otzpt usa este). Instalação
  • V-Agent: fork simplificado do Zed, feito pelo otzpt. Interface mais fácil de usar e melhor integração com IA. O upload para o robô faz-se com o arduino-cli. GitHub

Opção 1: Arduino IDE

  1. Abre o main.ino.
  2. Ferramentas > Placa: escolhe a placa do robô.
  3. Ferramentas > Porta: escolhe a porta onde o robô aparece.
  4. Carrega no botão de upload (seta para a direita).

Opção 2: arduino-cli (sem Arduino IDE)

Instalação e documentação: arduino.github.io/arduino-cli. Instala com o gestor de pacotes da tua distribuição ou com o script oficial da documentação.

Instalação com o script oficial (instala em ./bin na pasta atual):

curl -fsSL https://raw.githubusercontent.com/arduino/arduino-cli/master/install.sh | sh

Depois move o ficheiro bin/arduino-cli para uma pasta do teu PATH, por exemplo ~/.local/bin. No Windows, usa o instalador da página de instalação.

Os comandos abaixo usam arduino:avr:uno como exemplo. Troca pela placa real do robô.

arduino-cli core update-index
arduino-cli core install arduino:avr          # so uma vez
arduino-cli board list                        # mostra a porta e a placa
arduino-cli compile --fqbn arduino:avr:uno .
arduino-cli upload -p /dev/ttyACM0 --fqbn arduino:avr:uno .
arduino-cli monitor -p /dev/ttyACM0 -c baudrate=115200

Corre estes comandos dentro da pasta do projeto. O ficheiro .ino tem de ter o mesmo nome da pasta, ou a pasta deve ter um só .ino.

Permissões no Linux

Se o upload falhar com "permission denied", o teu utilizador não tem acesso à porta serie. O grupo certo depende da distribuição (por exemplo dialout em Debian/Ubuntu, uucp em Arch). Vê com ls -l /dev/ttyACM0 qual é o grupo da porta.

Erros comuns

  • Porta não aparece: o cabo é só de carga. Usa um cabo de dados.
  • Upload falha: fecha o Serial Monitor, só um programa usa a porta de cada vez.
  • Placa errada: o compile pode passar e o upload falhar. Confirma com arduino-cli board list.

Nota

Estes comandos não foram testados no robô da equipa. Confirma a placa e a porta antes de usar.
