Código, o básico

O robô usa C/C++ para Arduino. Um programa chama-se sketch e tem sempre duas funções. Esta página é um resumo. O guia completo está em ARDUINO_C_BASICS.md (em inglês).

Estrutura

void setup() {
  // corre uma vez quando o robô liga
  Serial.begin(115200);
}

void loop() {
  // corre sem parar
  Serial.println("ola");
  delay(1000);
}

O Serial.println escreve no Serial Monitor. Quando algo não funciona, imprime os valores.

MicroPython

MicroPython é Python para microcontroladores. Só corre em placas suportadas (por exemplo Raspberry Pi Pico e ESP32). Um Arduino Uno não corre MicroPython, por isso esta secção só serve se o robô usar uma dessas placas. Documentação: docs.micropython.org. Para escrever e enviar ficheiros podes usar o Thonny ou o mpremote.

O ficheiro main.py corre quando a placa liga. Não há setup e loop, escreves o ciclo tu. Os números dos pins mudam de placa para placa, confirma na documentação da tua. 

from machine import Pin, ADC, PWM
import time

led = Pin(25, Pin.OUT)          # saida (25 e o LED da Pico)
botao = Pin(14, Pin.IN, Pin.PULL_UP)
sensor = ADC(Pin(26))           # entrada analogica
motor = PWM(Pin(15))
motor.freq(1000)

while True:                     # equivale ao loop()
    led.value(1)                # liga (0 desliga)
    if botao.value() == 0:      # com PULL_UP, carregado le 0
        motor.duty_u16(40000)   # velocidade de 0 a 65535
    leitura = sensor.read_u16() # 0 a 65535
    print("sensor:", leitura)
    time.sleep(0.5)             # segundos

Diferenças para o C

  • A indentação define os blocos. Não há { } nem ;.
  • Não declaras tipos: velocidade = 200.
  • time.sleep() usa segundos, delay() usa milissegundos. Para ms usa time.sleep_ms().
  • Funções: def andar(velocidade):.
  • Os valores analógicos e PWM têm escala de 0 a 65535, não 0 a 1023 ou 0 a 255.
  • É mais lento que C. Para ler sensores muito depressa, C é melhor.

Erros comuns

  • = em vez de == dentro de um if.
  • Falta de ; ou de uma }. O erro aponta perto, não no sítio exato.
  • Esquecer o pinMode.
  • Baud rate do Serial Monitor diferente do Serial.begin.
  • Ligar motores diretamente aos pins. Usa sempre uma ponte H e bateria própria, com o GND partilhado.
